## 一条轨道，一个原生导航所有者

大纲提供完整历史，已加载节点提供细粒度语义。未加载的 `turn:N` 在加载后由第一段继承，
后续段保持节点身份。窗口限制可见槽位，不是历史总量。

原生 ChatView 拥有分页、滚动补偿、底部跟随和阅读恢复。Piano 通过校验后的按钮转发
动作，不维护另一个分页器或滚动状态机。接管成功只显示一条导航；失配恢复原值。

## 语义与折叠

输入、过程、最终结果、提问和回答分别投影。一般工具只截断文本连续性；结构化问答
使用独立投影并处理重复调用身份。可揭示的隐藏过程和问答也可以生成键；挂载 DOM
的实际可见性优先于来源节点的折叠提示。

过程折叠只合并同轮连续输出，历史入口与关键语义边界保持独立；一个折叠键只占一个
槽位。手动展开与悬停/被动滚动解耦。导航退出后记录已回折成员，避免阅读保护立即拆开。

## 调度与生命周期

结构、轮次、DOM、布局、原生状态、keyed 内容、阅读和指针使用不同脏标记，在同一 rAF
合并。纯指针帧只处理最新坐标、一次绘制宽度命中、可见键及必要预览，不扫描正文或
重建投影。视觉波峰使用连续坐标，语义选中仍指向具体可见键。横向悬停使用固定基础键体；
点击单独读取实际绘制长度。96ms 有限幅度包络只在进入/退出期间请求后续指针帧，
折返从当前幅度转向，不对 Y 再做时间缓动。失焦、键盘、点击、回退和切会话清除旧包络。

同一语义段内的滚动早退。稳定形状的文字按轮次刷新，语义重算最小间隔为 120ms；
工具或结构变化仍可能引发更广重建，不能宣称所有流式更新均为常数成本。

Observer 只关注有意义的结构边界与契约属性，避免逐 token 的 Markdown 变化唤醒全局
路径。键 DOM 按稳定 key 复用；鼠标停止后无常驻循环。键盘/退出悬停保留短宽度过渡。
原生导航的结构观察覆盖 scrollport 和 ChatView 中 flow 的直接父容器；导航暂时
消失时保留仍连接的原 slot 观察，稍后重挂载即可恢复接管，不依赖输入框事件。
该观察不下探正文子树，卸载时与其他 Observer 一并释放。

包身份是 `dsh-piano-nav`，设置 entry 仍是 `sm-context-piano`；新旧包不能同时装载。
偏好尚未确认时不抢占原生导航。切换会话或卸载时取消本地事务与待落地意图，释放
订阅、Observer、监听、timer、rAF、DOM 和样式；旧异步回调失效，错误日志不含正文。

## 设置预览与配色

远端设置控制器为每类颜色保留一份最新待确认值，色块、图例、预览和实际轨道共享
该值；`saving` 明示后台持久化仍未完成，revision 仍代表已确认文档。每个写入批次
只清理自己仍拥有的预览，失败回退到最新已确认值，较旧响应不能覆盖新选择。
语言、启用和尺寸等非颜色字段仍使用宿主确认值；串行写入与同字段待执行合并规则不变。

颜色覆盖以平铺字段进入原 settings entry。host schema 和客户端 decoder 共用严格 hex
校验；空值表示主题自动色，未知/非法值不会写入 CSS。设置页与轨道共用配色变量与
语义 CSS，预览还复用 projectRailSlots、visibleWindow 与 stackPositions，不挂载会话探针
或第二套导航所有者。恢复默认从统一字段清单生成 unset 操作。

纯配色变化只增量更新对应的普通/强调色 CSS 变量，不调度轨道渲染、导航投影或几何读取。
设置页按字段订阅：拖动只刷新对应颜色行；预览独立更新变量，避免整页 React 重渲染和
无关区域样式失效。控制器缓存已确认设置，保持同值快照身份稳定；持久化状态与实际值
分开通知，共享保存 Promise 只挂一份反馈处理。布局设置仍重算几何，语言改变仍重建
缓存的翻译标题。仅恢复配色时，六个 unset 通过同一远端 mutation 提交，
不会因多次请求中途失败而留下部分重置。用户自选颜色保留原色，活动态
通过主题背景色混合增强；设置页原生选色控件监听 DSH 主题属性，自动色随主题切换。
