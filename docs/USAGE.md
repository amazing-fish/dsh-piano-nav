# 使用指南

[返回首页](../README.md)

## 安装

```powershell
dsh plugin --profile web add dsh-piano-nav
```

刷新 Web GUI，在“琴键导航 / Piano Navigator”中启用。只有当前可见会话挂载轨道。
尚未发布时，可先构建并链接仓库：

```powershell
pnpm build
dsh plugin --profile web add link:C:/projects/dsh-sm-context-piano
```

## 从旧包迁移

1. 找到 profile 中旧包 `@hjj345345/dsh-sm-context-piano` 或旧 `link:` 的加载条目。
   用 `dsh plugin --profile web --help` 核对本机的移除命令，移除旧加载条目，
   避免同时注册两套设置页、样式和会话探针。
2. 添加新包并刷新。DSH patch 的 entry id、设置 namespace 和设置页 id 保持
   `sm-context-piano`。保留该 entry 的持久化设置即可继续读取原偏好。

清理整个设置 entry 可能重置偏好；包改名不会自行恢复被清理的数据。
旧作用域包的发布和废弃状态由其原维护者控制。

## 导航与过程折叠

普通键预览语义文本，激活后定位。未加载历史只有已有大纲；加载和落点交给原生动作。
原生按钮暂时不在可用窗口时，个别历史入口可能暂时禁用。

过程折叠只合并同轮连续 AI 输出，一枚折叠键只占一个槽位。历史轮次、输入、提问、
回答、最终结果和加载/失败保护轮次保持独立。

- 首次激活折叠键只展开，不滚动正文；再次激活成员才定位。
- 原生过程区若可揭示，先通过原生 `beforematch` 展开，再定位；问答卡片也只展开，不提交答案。
- 正文被动滚动、鼠标离开、失焦和流式更新保留显式展开。
- 激活成员或其他键、切换折叠组、Escape、轨道滚轮或切换会话收回展开；不可导航历史键的显式激活也收回当前组。
- 超过窗口容量的组可以通过方向键和窗口浏览继续访问成员。

## 指针与键盘

波峰按鼠标纵坐标连续变化，预览对应最近的可见键。命中范围使用实际绘制宽度加小容差，
空白边缘不会触发动作。指针直接跟随；键盘选择和退出悬停使用短过渡，减少动画即时更新。

`↑/↓` 移动选择；`PageUp/PageDown` 按窗口数量前后移动；`Home/End` 选择完整列表首尾。
`Enter/Space` 显式激活，`Escape` 关闭预览、收回展开并撤销待落地意图。

轨道滚轮只浏览轨道；正文滚动更新阅读键。取消待落地意图不会中止 DSH 已发出的共享
网络请求，但不得在完成后再把阅读位置拉回旧目标。

## 设置

| 字段 | 默认值 | 范围 |
| --- | --- | --- |
| 语言 | 简体中文 | 简体中文 / English / 繁體中文 |
| 启用 | 开启 | 开 / 关 |
| `keyHeight` | 2px | 1–4 的整数 |
| `keyGap` | 12px | 6–18 的整数，中心到中心 |
| `maxVisible` | 20 | 5–30 的整数 |

高度为 `(maxVisible - 1) × keyGap + keyHeight`。插件语言控制设置页和语义预览；
一级导航名称和轨道无障碍名称随 DSH 全局语言。设置由 DSH live settings 持久化。

## 没有显示或不能定位时

容器过窄、与正文重叠、没有目标、原生契约失配或尚未确认启用偏好时，Piano 隐藏或
交还原生导航。多个语义段可能共享一行锚点，落在同一行起点。

查看[兼容说明](COMPATIBILITY.md)。反馈中提供 DSH/插件版本、普通/紧凑模式、复现动作，
以及 `window.__smcpDebug` 的 mode/hiddenReason/nativeReject；避免提交会话正文或凭据。
