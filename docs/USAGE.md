# 使用指南

[返回首页](../README.md)

## 安装

```powershell
dsh plugin --profile web add dsh-piano-nav
```

刷新 Web GUI，在“琴键导航 / Piano Navigator”中启用。只有当前可见会话挂载轨道。
本地开发时，可先构建并链接仓库：

```powershell
pnpm build
dsh plugin --profile web add link:C:/projects/dsh-piano-nav
```

## 从旧包迁移

1. 找到 profile 中旧包 `@hjj345345/dsh-sm-context-piano` 或旧 `link:` 的加载条目。
   用 `dsh plugin --profile web --help` 核对本机的移除命令，移除旧加载条目，
   避免同时注册两套设置页、样式和会话探针。
2. 添加新包并刷新。DSH patch 的 entry id、设置 namespace 和设置页 id 保持
   `sm-context-piano`。保留该 entry 的持久化设置即可继续读取原偏好。

清理整个设置 entry 可能重置偏好；包改名不会自行恢复被清理的数据。
旧作用域包的发布和废弃状态由其原维护者控制。

## 导航与过程折叠

普通键预览语义文本，激活后定位。未加载历史只有已有大纲；加载和落点交给原生动作。
原生按钮暂时不在可用窗口时，个别历史入口可能暂时禁用。

过程折叠只合并同轮连续 AI 输出，一枚折叠键只占一个槽位。历史轮次、输入、提问、
回答、最终结果和加载/失败保护轮次保持独立。

- 首次激活折叠键只展开，不滚动正文；再次激活成员才定位。
- 原生过程区若可揭示，先通过原生 `beforematch` 展开，再定位；问答卡片也只展开，不提交答案。
- 正文被动滚动、鼠标离开、失焦和流式更新保留显式展开。
- 同组成员间定位保留展开；激活其他类型键、切换折叠组、Escape、轨道滚轮或切换会话收回展开；不可导航历史键的显式激活也收回当前组。
- 超过窗口容量的组可以通过方向键和窗口浏览继续访问成员。

## 指针与键盘

波峰按鼠标纵坐标连续变化，预览对应最近的可见键。横向悬停以基础键体加 3px 容差
为相同的进入/退出边界：普通键基础长 10px，当前阅读键 24px；放大波形不扩大悬停区。
进入和退出时幅度使用 96ms 短过渡，Y 位置仍直接跟随；折返从当前幅度接续。退出立即
关闭语义预览，收势只保留视觉效果。放大部分不是延伸的悬停区，点击仍按实际绘制宽度
加小容差判定，空白边缘不会触发动作。键盘选择保留短过渡，减少动画即时更新。

`↑/↓` 移动选择；`PageUp/PageDown` 按窗口数量前后移动；`Home/End` 选择完整列表首尾。
`Enter/Space` 显式激活，`Escape` 关闭预览、收回展开并撤销待落地意图。

轨道滚轮只浏览轨道；正文滚动更新阅读键。取消待落地意图不会中止 DSH 已发出的共享
网络请求，但不得在完成后再把阅读位置拉回旧目标。

## 设置

| 字段 | 默认值 | 范围 |
| --- | --- | --- |
| 语言 | 简体中文 | 简体中文 / English / 繁體中文 |
| 启用 | 开启 | 开 / 关 |
| `keyHeight` | 2px | 1–4 的整数 |
| `keyGap` | 12px | 6–18 的整数，中心到中心 |
| `maxVisible` | 20 | 5–30 的整数 |

1.3.1 增加颜色与图例：输入、过程输出、提问、回答、最终结果、历史入口分别绑定
`colorInput`、`colorOutput`、`colorQuestion`、`colorAnswer`、`colorFinal`、`colorHistory`。
字段为六位 `#RRGGBB`，空字符串使用主题默认色。仅点击 32px 色块打开取色器，文字和空白不触发。
保存返回前保留最新选色；写入失败时在常驻提示区显示错误并恢复已保存颜色，重试期间保留错误，成功保存后清除。选择颜色后通过 DSH live settings
保存，图例、布局预览和实际琴键同步；当前键/悬停在同色系内加强强调，文字与形状仍
标明语义。自选颜色应用于深浅两种主题，请分别检查可辨识性；“自动”恢复单类主题色，
“恢复默认配色”保留其他偏好，“恢复默认值”重置全部字段。旧设置缺少颜色字段时沿用默认。

历史入口默认在浅色主题使用深色、深色主题使用浅色；自选 `colorHistory` 同步实际键的
描边、图例和预览，当前/悬停描边沿用该颜色的强调色。未加载键保留透明背景，1–2px
键高下描边占满键身，不保证可见的空心内部；设置页用同一种描边展示历史入口。

布局预览按展开后演示键所需空间预留高度，并受最大可见数量限制，使用实际折叠投影；点击过程组展开，同组成员选择保留展开，
点击其他类型键回折，卡片高度保持不变。容量小于 8 枚时始终显示首尾浏览按钮。它不执行会话导航。最大数量统计窗口内显示键数，折叠组计一枚，不是历史条目或过程成员总数。

高度上限为 `(maxVisible - 1) × keyGap + keyHeight`，实际高度和容量可能被可用空间缩小。
插件语言控制设置页和语义预览；
一级导航名称和轨道无障碍名称随 DSH 全局语言。设置由 DSH live settings 持久化。

## 没有显示或不能定位时

容器过窄、与正文重叠、没有目标、原生契约失配或尚未确认启用偏好时，Piano 隐藏或
交还原生导航。多个语义段可能共享一行锚点，落在同一行起点。

查看[兼容说明](COMPATIBILITY.md)。反馈中提供 DSH/插件版本、普通/紧凑模式、复现动作，
以及 `window.__smcpDebug` 的 mode/hiddenReason/nativeReject；避免提交会话正文或凭据。
