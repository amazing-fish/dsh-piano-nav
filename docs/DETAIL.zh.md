# DSH 琴键导航

面向 DeepSeek Harness Web GUI 的语义会话导航轨道。在正文左侧呈现支持鼠标连续跟随的琴键条，帮助你在长 Agent 会话中快速预览与定位任意轮次和关键节点。

## 琴键语义

| 琴键 | 含义 |
| --- | --- |
| 用户输入 | 用户主动发送的消息与中途引导（steering） |
| AI 过程输出 | 中间过程文本；同轮连续过程自动折叠为一枚紧凑键 |
| 最终结果 | 每轮的最终回答，与过程输出分开标识 |
| AI 提问 / 用户回答 | 结构化 `ask_user_question` 问答及其状态 |
| 未加载历史 | 真实历史轮次大纲，点击后交由 DSH 原生导航加载并定位 |

## 常用操作

- **沿轨道移动鼠标：** 连续波形放大，并在旁侧显示最近琴键的纯文本预览。
- **点击 / `Enter` / `Space`：** 定位到目标段落，或触发未加载历史轮次的原生加载。
- **点击折叠过程组：** 一次展开并定位到首条过程输出；轨道滚轮浏览保留展开态，点击其他类型键或按 `Escape` 收回。
- **键盘导航：** 支持 `↑` / `↓`、`PageUp` / `PageDown`、`Home` / `End`、`Enter` / `Space` 与 `Escape`。

## 设置与数据边界

可在设置页或插件管理页中的 **琴键导航 / Piano Navigator** 调整语言（简体中文 / English / 繁體中文）、琴键粗细、间距、窗口可见数量及六类语义配色。

插件只读取导航信息、展示纯文本预览并保存自身设置；不改写会话消息、不注入系统提示词、不提交问答回应。容器过窄或宿主结构变化时自动回退并恢复 DSH 原生导航。
