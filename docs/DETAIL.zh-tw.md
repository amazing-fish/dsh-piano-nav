# DSH 琴鍵導覽

面向 DeepSeek Harness Web GUI 的語義會話導覽軌道。在正文左側呈現支援滑鼠連續跟隨的琴鍵條，協助你在長 Agent 會話中快速預覽與定位任意輪次與關鍵節點。

## 琴鍵語義

| 琴鍵 | 含義 |
| --- | --- |
| 使用者輸入 | 使用者主動輸入的訊息與中途引導（steering） |
| AI 過程輸出 | 中間過程文字；同輪連續過程自動折疊為一枚緊湊鍵 |
| 最終結果 | 每輪的最終回答，與過程輸出分開標示 |
| AI 提問 / 使用者回答 | 結構化 `ask_user_question` 問答及其狀態 |
| 未載入歷史 | 真實歷史輪次大綱，點擊後交由 DSH 原生導覽載入並定位 |

## 常用操作

- **沿軌道移動滑鼠：** 連續波形放大，並在旁側顯示最近琴鍵的純文字預覽。
- **點擊 / `Enter` / `Space`：** 定位至目標段落，或觸發未載入歷史輪次的原生載入。
- **點擊折疊過程群組：** 一次展開並定位至首條過程輸出；軌道滾輪瀏覽保留展開態，點擊其他類型鍵或按 `Escape` 收回。
- **鍵盤導覽：** 支援 `↑` / `↓`、`PageUp` / `PageDown`、`Home` / `End`、`Enter` / `Space` 與 `Escape`。

## 設定與資料邊界

可在設定頁或外掛管理頁中的 **琴鍵導覽 / Piano Navigator** 調整語言（简体中文 / English / 繁體中文）、琴鍵粗細、間距、視窗可見數量及六類語義配色。

外掛只讀取導覽資訊、顯示純文字預覽並儲存自身設定；不改寫會話訊息、不注入系統提示詞、不提交問答回應。容器過窄或宿主結構變化時自動回復 DSH 原生導覽。
