## 本版行为

- 悬停跟随实际绘制琴键宽度加 3px 容差；可见放大段内保持预览。斜向移动使键在同帧变窄时复核边界，避免停下后保留越界悬停；保留有限起势/收势、折返与轻量更新。
- 历史键默认描边清晰，自选配色与实际键、图例和预览共享。保留透明背景和既有键尺寸。
- 设置预览按演示内容缩紧，同组灰键成员导航保持展开；取色器只在 32px 色块触发，异步保存保留最新草稿。
- 提示区、预览展开和窄屏说明预留空间，连续失败重试不引起整页布局跳动；复制提示忽略过期返回。
- 同一颜色字段尚未执行的连续写入保留最新值，不跨越其他字段或重置；失败控制台保留宿主原始错误诊断。

对应实现与后续修复：PR #41 / #45 / #46 / #48 / #50 / #52，均已合并。
